# PRODUCT_PRINCIPLES.md

## Product Identity
This is a DroNet-inspired visual navigation prototype.

It should communicate image-based navigation reasoning clearly, practically, and visually.

It is not a real drone-control system, robotics simulator, or generic AI dashboard.

## Audience
Faculty, students, evaluators, and non-specialist viewers.

## Experience Goals
- Clear input display.
- Visible model/navigation behavior.
- Explainable outputs.
- Presentation-friendly interface.
- Focused demo without clutter.

## Design Taste
- Clean, minimal, Apple-adjacent visual language.
- Avoid cluttered dashboards.
- Avoid loud colors unless showing status or risk.
- Prefer spacing, hierarchy, and useful visual aids.

## Non-Goals
- Real drone deployment.
- Hardware integration.
- Regulatory workflows.
- Enterprise SaaS polish.
- Background data collection.
- User tracking.

## Doctrine
If a feature makes the project harder to explain, harder to run, or harder to inspect, it must justify itself.
