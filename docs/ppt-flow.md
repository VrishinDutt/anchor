# Anchor PPT Flow

## Slide 1 — Title
Anchor: A Metacognitive AI Agent for Digital Autonomy  
Subtitle: Responsible AI use without surrendering user agency.

## Slide 2 — Problem
AI tools are powerful, but answer-first systems can create:
- false mastery
- passive outsourcing
- reduced critical thinking
- digital dependency

## Slide 3 — Core Idea
Anchor helps users use AI without surrendering agency to AI.

## Slide 4 — Why Not a Generic Chatbot?
Generic chatbot:
User → LLM → Answer

Anchor:
User → Local agent → Policy check → Scaffold/action → Optional Claude

## Slide 5 — Objectives
- Build a concrete desktop AI agent
- Preserve user agency
- Detect over-outsourcing
- Generate grounded next actions
- Use Claude only when explicitly invited

## Slide 6 — SDG Alignment
Primary:
- SDG 4: Quality Education
- SDG 3: Good Health and Well-being

Supporting:
- SDG 9: Innovation
- SDG 12: Responsible Consumption

## Slide 7 — PEAS
Performance: clarity, agency, next action  
Environment: user’s digital/academic task context  
Actuators: chat, action card, Claude assist, session export  
Sensors: text input, session state, artifacts, constraints

## Slide 8 — Agent Type
- Model-based: remembers active task
- Goal-based: moves user toward grounded action
- Utility-aware: Decision Lens
- Rule-based: explainable policy engine

## Slide 9 — System Architecture
User Input → Task Parser → Agency Risk Detector → Policy Engine → Local Response → Action Card → Optional Claude Assist

## Slide 10 — LLM Policy Layer
Claude is subordinate.
It is not called automatically.
Anchor decides:
- blocked
- scaffold-only
- bounded-generation

## Slide 11 — UI/UX
Minimal Apple-widget-like UI:
- main thread
- focus card
- optional drawers
- hidden diagnostics
- pastel fixed-light visual system

## Slide 13 — Ethics
Anchor is not:
- therapist
- diagnosis tool
- crisis system
- replacement for human support

## Slide 14 — Future Scope
- LLM review mode
- local model support
- user-owned memory
- packaged macOS/Windows app
- mobile companion

## Slide 15 — Conclusion
Anchor demonstrates responsible AI agency by helping users hold the thread, preserve agency, and take grounded action.
